# Examples — Mpichi Dataset (Lot 4)

## RAG / retrieval demo

Pure-Python TF-IDF over `data/recipes.jsonl` (no GPU). Optional `sentence-transformers`.

```bash
cd mpichi-dataset
python3 examples/rag_demo.py
python3 examples/rag_demo.py --query "accompagnement pour moambe" --k 5
python3 examples/rag_demo.py --eval
```

Baseline metrics (TF-IDF, eval gold `recipe_ids`) are printed by `--eval` and recorded in [BASELINE.md](BASELINE.md).

## Eval split

Human-reviewed / semi-generated Q&A: [`data/eval/qa.jsonl`](../data/eval/qa.jsonl) (~95 items).

| task | Focus |
| --- | --- |
| `alias_to_dish` | Local / regional name → dish |
| `region_of_dish` | Dish → `region_id` / label |
| `region_dishes` | Region → dishes |
| `list_ingredients` | Ingredient list |
| `structured_ingredient` | Parsed amount/unit |
| `pairing` | Accompaniment suggestions |
| `category` | plat / accompagnement / … |

Schema sketch: each line has `id`, `task`, `lang`, `question`, `answer`, `recipe_ids[]`, `notes`.
